Connect your waitlist backend

This dashboard reads signups from a Google Sheet through a small Apps Script endpoint. Once it's connected, every entry from the site's waitlist form will show up here automatically.

  1. Create a Google Sheet and open Extensions → Apps Script.
  2. Paste in the code from apps-script/Code.gs in this repo.
  3. Set your own ADMIN_KEY in that file — this becomes your admin password.
  4. Deploy it as a Web app (Execute as: Me, Access: Anyone).
  5. Copy the URL and paste it into WAITLIST_ENDPOINT in both admin.html and index.html.
